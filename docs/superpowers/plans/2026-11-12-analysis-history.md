# 账单分析与会话历史实施计划

用户需要通过已有账本做综合分析、预测和条件推演，并在手机端找回历史对话。现有流程只有一次查询规划和简单汇总，前端缺少历史读取接口。

## 实施约定

- 沿用 FastAPI、Vue、MongoDB、现有授权账本客户端和家用模型。
- 查询负责取得真实账单，计算工具提供可核验的数值证据，模型负责解释、综合判断和提出必要的补充问题。
- 工具覆盖收支结构、时间趋势、变化原因、异常、重复交易、周期性收支、预测和假设场景。分析计划可组合多个工具。
- 预测默认读取最近六个完整自然月及本月，明确未完月份、空白月份、非经常入账和数据不足。情景输入保留用户假设，收入和支出均支持。
- 会话读取沿用服务端账号及账本权限，支持分页、续聊和新对话。兼容既有记录。
- 使用合成数据验证分析口径。线上诊断只输出不包含对话原文、账单金额或凭据的验证结果。
