# 意图理解与分析验收（2026-11-19）

本轮重点是理解用户目标、利用既有条件和证据、选择正确的分析工具。图表属于计算结果的展示，不作为理解能力的替代。

## 分层判断

1. **理解与计划**：本轮是独立问题、承接、纠正还是重置；目标月份、历史窗口、账本、来源、保护项和已有价格是否准确继承；是否查询/计算了问题需要的内容。
2. **计算与交付**：金额、成员、来源、筛选、笔数、均额和变化贡献是否准确；表格是否交付，未知是否仍为未知。
3. **解释**：是否把历史变化说成未来假设，是否凭收入名称判断稳定性，是否把结余当余额，是否误判目标和储备缺口。

`validation.status=grounded` 仅核对正文与同范围程序发现一致，不能证明第一层已经正确。真实模型回归和独立人工复核仍是发布依据。

## 样本和运行方式

所有可提交的回归均用虚构账本，经正常 Agent 入口执行，不向生产历史写入合成问题。

| 回归 | 次数 | 重点 |
| --- | ---: | --- |
| `scripts.evaluate_intent` | 10 | 四轮收入预测/表格/备注查证/方法回指、家庭成员归属、三轮支出与购买决策、两轮跨维统计 |
| `scripts.evaluate_acceptance` | 16 | 综合诊断、变化、抗风险、预测、优化、购买、储蓄、数据质量、四轮条件承接及四个输入变体 |

固定环境：家庭主机 Qwen3.5:9b、Ollama 0.40.16、8K 上下文、GPU 34 层、单模型串行、空闲驻留 60 秒；意图、规划、报告提纲关闭推理且零温度。程序不依赖无界思维链。

基础样本的最近完整月份预测月收入 6600、月支出 2600、月新增结余 4000；三个月累计新增 12000。家教来源基准 1600，减半后每月少 800，三个月 9600，延至五个月 16000。最近月份支出增长 900 来自医疗，房租和餐饮未增长。完整月份月均结余 3850 与预测结余 4000 是不同口径。

购买变体：可动用 12000、买价 6000、保留储备 5000，则买后现金 6000、储备余量 1000。全部停薪且支出按 2600 延续，可动用 10000 对应约 3.85 个月。未给余额时不能生成覆盖时长；未给明确目标时不能量化延期降低多少月储蓄要求。

## 发现及架构修正

早期自由写作版本的 R24 自动必要检查为意图 8/10、分析 14/16，独立复核仍发现多处实质错误：历史医疗变化误写为未来已计入、保护项变成节支建议、月度结余能力与目标要求混淆。这说明自动检查和模型自审都不足以证明解释正确。

v5 保留意图解析、结构化条件、计划核对和来源调查，报告只允许模型选择提纲和证据。归因、可行性、未知条件及行动建议由程序发现生成，删除自由财务写作与模型自审。另对回指丢失和已知价格被再次询问添加真实失败形态回归。

## 验证边界

- 单元测试验证计算、权限、上下文与输出合同；不代表模型语义效果。
- 浏览器移动尺寸已验证历史恢复、账本切换、表格图表、CSV/PNG 和页面布局；使用合成样本。
- 真实账本验收结果只保存在主机私有目录，不提交具体金额、账号或对话。
- USB 设备未连接时不能证明 Android WebView、通知监听、下载或 APK 覆盖安装通过。
