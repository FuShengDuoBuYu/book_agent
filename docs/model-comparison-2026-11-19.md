# 账本对话模型对照：2026-11-19

## 方法与边界

比较的是相同 Agent 下的实际任务完成情况。用户所说的“Codex”在这里具体指官方 OpenAI API 的低费用模型，不是桌面 Codex 的工具、终端或权限。没有使用 Astra。

固定虚构账本和十组、三十轮中文问答；通过正常 `BookAgent.chat` 执行。每组保留真实的最近十二条消息窗口，跨成员与个人/家庭范围重新建会话。模型配置使用 8K 上下文预算、规划输出 2048、关闭深度推理；本地 Qwen 使用 Ollama 0.40.16、GPU 34 层、空闲 60 秒释放。API 使用 Responses 严格结构化输出，省略温度参数。

初始 Agent 修订为 `f8db882be3729a9bd30dad1ad26ba5e68a94ba94`。评测期间不改模型正在读取的应用源码。评分器修复后可重新读取保存的答案与实际执行证据，无需重调模型；它不向模型反馈分数，也不更改题目和账本。运行目录同时保存应用修订、配置、runner SHA256、原始 JSONL、用量和 GPU 采样，真实账本不混入这组评测。

自动检查独立核对查询范围、实际历史参考月、金额、笔数、均额、来源、表格及条件继承。整轮人工复核还检查附表是否与主结论矛盾、有没有漏答、把推测当事实。`grounded` 仅表示报告与计算发现一致，不等于完成用户目标；多轮题互相关联，本次通过率也不能外推为所有真实提问的成功率。

## 初始 Qwen 结果

一次完整 30 轮运行共约 1203 秒。独立人工复核 16 轮通过、14 轮失败。主要失败形态如下。

| 问题 | 实际交付 | 独立期望 | 归因边界 |
| --- | --- | --- | --- |
| 询问收入 | 回答月结余 2020 | 收入 3700，来源 3200+500 | 模型选了 `net`，日期本身正确 |
| 项目减半但仍三个月 | 擅自改五个月、8850 | 三个月5310 | 期限与上下文执行错误 |
| 撤回减半假设 | 仍给5310 | 恢复6060 | 撤销条件没有生效 |
| 取消四个月期限 | 仍呈现四个月目标要求 | 只回答按原结余约五个月 | 退役期限没有生效 |
| 已提供购买余额12000 | 再次索要余额 | 买后11300、储备余量6300 | 已知输入未进入执行，不能笼统叫算术错误 |
| 主推演6060正确 | 附表把项目备注当分类，基准收支全0 | 整份报告同口径且无矛盾 | 仅检查主金额会漏报 |

归并来源在局部调查后丢掉“调版”、无效新分组挡住旧确认分组，以及未明确交付空大额异常结果，属于可修复的 Agent 路径，需和模型能力分开报告。按支付方式分别展示两个月的合法分期明细与合计等价，评分器不能因多一列而误拒。

## API 和后续修复

初始同代码对照中，Luna 已完成三十轮：自动检查20轮通过，独立人工复核也为20轮通过、10轮未完成；Qwen 自动18轮、人工16轮。Luna 中位耗时约23.3秒，Qwen约32.8秒；Luna 仍有报告遗漏、错误筛选及执行失败，尚不能据此宣布达到发布质量。Terra 对照与修复后回放仍在执行。已遇到供应商对正常账单分析返回 `400 invalid_prompt`。这属于请求失败，不能作为零费用或模型成功；原始失败记录保留，未通过修改提示绕过拒绝。

默认评测在费用未知时停止。为了完成本次有限题集，显式启用每个未知费用轮 0.10 美元的预算预留，总承诺限额 1 美元；已知调用估算另计。预留是调用者的预算管理数，不是实际账单，也不是费用上界。结果中的真实估算仍标记未知。推理 token 已包含在输出中，不重复计费。本地 Qwen 没有供应商 API 调用费，仍有电力和设备成本。

完整原始合成输出保存在家中 `/opt/ai-bill/staging/openai-acceptance/runs/` 私有目录，用于后续复核；真实用户账本验收使用另一私有目录，不提交金额、账号或具体对话。


## 已确认的共同程序缺陷

Luna 和 Qwen 在“取消截止日期”轮的模型计划核对，都正确给出 `savings.months=null`，但条件继承随后把旧的四个月重新加回。两轮端到端失败保留，不能归因为两模型都没听懂。口语金额“一万二”“两万二”也因程序主动拒绝而删除了正确的余额、目标。这两处修复和来源保持、负结果交付、失败审计须通过真实模型回放后再评估最终默认模型。

Luna 的三十条实际问题、账本日期和 fixture 指纹与 Qwen 逐条一致。人工通过不是照抄自动检查：Luna 切换到另一成员后正确直接澄清余额，虽未调用查询也可完成该轮；异常检查已有空结果却未明确交付，则整轮仍未完成。供应商拒绝请求但代码仍给出正确答案时，答案完成度和接口失败分别记录。
